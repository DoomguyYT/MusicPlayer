## 📖 Описание

**Music Player** — это полнофункциональный десктопный музыкальный плеер, который объединяет возможности локального проигрывателя и интернет-радио. Приложение поддерживает популярные аудиоформаты, отображает метаданные треков, позволяет создавать плейлисты и получать информацию о текущем треке в реальном времени для интернет-радиостанций.

Проект демонстрирует навыки:
- Разработки на **C#** с использованием **WPF** и паттерна **MVVM**
- Работы с аудио через **NAudio**
- Чтения и записи метаданных через **TagLib#**
- Получения **ICY-метаданных** от интернет-радиостанций
- Асинхронного программирования (async/await)
- Создания современного пользовательского интерфейса
- Работы с файловой системой и сериализацией плейлистов в JSON

## 🚀 Возможности

### 🎵 Воспроизведение
- Поддержка форматов: **MP3, WAV, FLAC, AAC, OGG**
- Воспроизведение интернет-радио по URL
- Регулировка громкости
- Перемотка трека
- Режимы: **Повтор (все/один)** и **Перемешивание**

### 📋 Плейлисты
- Создание и удаление плейлистов
- Добавление треков через файлы или папки
- Drag & Drop — перетаскивание файлов в окно
- Сохранение плейлистов в JSON
- Поиск по плейлисту

### 🌐 Интернет-радио
- Воспроизведение потоков по URL
- Отображение названия трека в реальном времени (ICY-метаданные)
- Встроенные популярные радиостанции:
  - Radio Record
  - Europa Plus
  - Русское Радио
  - Rock FM
  - DFM
  - Love Radio
  - Хит FM

### ⌨️ Управление
- Горячие клавиши:
  - `Пробел` — Play/Pause
  - `F5` — Воспроизвести
  - `MediaNextTrack` — Следующий трек
  - `MediaPreviousTrack` — Предыдущий трек
  - `MediaStop` — Остановить

### 🎨 Интерфейс
- Красивый тёмный дизайн
- Отображение информации о текущем треке
- Индикатор статуса подключения к радио
- Адаптивный интерфейс

## 📦 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/yourusername/MusicPlayer.git
cd MusicPlayer
```

### 2. Установите зависимости

```bash
dotnet restore
```

## 💻 Использование

### Локальное воспроизведение

1. Нажми **📂 Открыть файлы** или **📁 Открыть папку**
2. Выбери аудиофайлы или папку с музыкой
3. Треки добавятся в текущий плейлист
4. Двойной клик по треку — начнётся воспроизведение

### Интернет-радио

1. Введи URL аудио-потока в поле ввода
2. Нажми **▶ Воспроизвести поток**
3. Или выбери станцию из меню **🌐 Интернет-радио → 📻 Радиостанции**

### Управление воспроизведением

| Кнопка | Действие |
|--------|----------|
| ⏮ | Предыдущий трек |
| ▶ / ⏸ | Play / Pause |
| ⏭ | Следующий трек |
| 🔁 | Повтор (все / один / выкл) |
| 🔀 | Перемешивание |

## 🔧 Дополнительная информация

### Поддержка ICY-метаданных

При воспроизведении интернет-радио приложение автоматически определяет и отображает название текущего трека для станций, поддерживающих протокол ICY.

**Проверенные станции:**
- Radio Record
- Europa Plus
- Русское Радио
- Rock FM
- DFM
- Love Radio
- Хит FM

### Форматы файлов

|--------|-----------|
| MP3 | ✅ Полная |
| WAV | ✅ Полная |
| FLAC | ✅ Полная |
| AAC | ✅ Полная |
| OGG | ✅ Полная |
